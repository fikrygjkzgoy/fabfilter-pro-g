## Overview

FabFilter Pro-G covers gating and expansion in six distinct styles from transparent to vintage with a visual hold and release display and comprehensive sidechain options.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FabFilter Pro-G** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Six Styles** | Clean, classic, opto, vocal, upward, and brickwall gate modes |
| **Visual Display** | Real-time visual gate activity and gain reduction display |
| **Sidechain** | External sidechain with filtering for frequency-selective gating |
| **Lookahead** | Lookahead mode opens gate before transient for transparent gating |
